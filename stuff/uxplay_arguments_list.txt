选项：
-n name   指定 AirPlay 服务器的网络名称（UTF-8/ASCII）
-nh       不在 AirPlay 服务器名称末尾追加 "@主机名"
-h265     支持 h265（4K）视频（需要安装 h264 插件的 h265 版本）
-hls [v]  支持 HTTP Live Streaming（目前仅支持 YouTube 视频）
          v = 2 或 3（默认 3），可选指定视频播放器版本
-scrsv n  屏幕保护覆盖 n：0=关闭 1=仅投屏活动期间保持开启 2=始终开启
-pin[xxxx] 使用 4 位 PIN 码控制客户端接入（默认：不使用）
          默认 PIN 为随机值：可选用固定 PIN xxxx
-reg [fn] 在 $HOME/.uxplay.register 中保留注册记录，用于校验回连客户端的
          PIN 注册信息；（可选）改用文件 "fn" 记录
-pw [pwd] 要求使用密码才能控制客户端接入；
          （不填密码时，每次连接都需要输入 PIN。）
          （"-pin" 之后再加 "-pw" 会覆盖前者，反之亦然）
-vsync [x] 镜像模式：用时间戳把音频同步到视频（默认）
          x 为可选的音频延迟：毫秒、小数、可为负值
-vsync no 关闭音频与（服务器端）视频的时间戳同步
-async [x] 仅音频模式：把音频同步到客户端视频（默认：不启用）
-async no 关闭音频与（客户端）视频的时间戳同步
-db l[:h] 把最小音量衰减设为 l dB（分贝，负值）；
          可选：把最大值设为 h dB（正负均可）默认：-30.0:0.0 dB
-taper    使用"渐变式"（tapered）AirPlay 音量控制曲线
-vol <v>  设置初始音频流音量：范围 [静音=0.0 : 1.0=满音量]
-s wxh[@r] 向客户端请求的视频显示分辨率 [刷新率]
          默认 1920x1080[@60]（使用 -h265 时为 3840x2160[@60]）
-o        开启显示"过扫描"（overscan）模式（一般不需要）
-fs       全屏（仅 X11、Wayland、VAAPI、D3D11/12、kms 有效）
-p        使用旧版端口 UDP 6000:6001:7011 TCP 7000:7001:7100
-p n      使用 TCP 与 UDP 端口 n、n+1、n+2，范围 1024-65535
          用 "-p n1,n2,n3" 分别指定三个端口，用 "n1,n2" 时 n3 = n2+1
          "-p tcp n" 或 "-p udp n" 分别设置 TCP 或 UDP 端口
-avdec    强制使用 libav 解码器进行软件 h264 视频解码
-vp ...   选择 GStreamer h264 解析器：默认 "h264parse"
-vd ...   选择 GStreamer h264 解码器：默认 "decodebin"
          可选值：（软件）avdec_h264；（硬件）v4l2h264dec、
          nvdec、nvh264dec、vaapih264dec、vtdec 等
          可选：avdec_h264、vaapih264dec、nvdec、nvh264dec、v4l2h264dec
-vc ...   选择 GStreamer 视频转换器：默认 "videoconvert"
          使用 v4l2h264dec 时的另一个选择：v4l2convert
-vs ...   选择 GStreamer 视频输出（videosink）：默认 "autovideosink"
          部分可选值：ximagesink、xvimagesink、vaapisink、glimagesink、
          gtksink、waylandsink、kmssink、fbdevsink、osxvideosink、
          d3d11videosink、d3d12videosink 等
-vs 0     仅串流音频，不显示视频窗口
-vrtp pl  用 rtph26[4,5]pay 把解码后的视频转发到别处："pl"
          是剩余的管线，从 rtph26*pay 选项开始：
          例如 "config-interval=1 ! udpsink host=127.0.0.1 port=5000"
-v4l2     使用 Video4Linux2 做 GPU 硬件 h264 解码
-bt709    使用 Video4Linux2 的树莓派机型有时需要此项
-srgb     以"全范围"[0-255] 显示颜色，而非"有限范围"[16-235]
          这是 GStreamer 某问题的临时规避方案，直到该问题被修复
-srgb no  关闭 srgb 选项（在默认开启的平台上使用：Linux、*BSD）
-as ...   选择 GStreamer 音频输出（audiosink）：默认 "autoaudiosink"
          部分可选值：pulsesink、alsasink、pipewiresink、jackaudiosink、
          osssink、oss4sink、osxaudiosink、wasapisink、directsoundsink
-as 0     （或 -a）关闭音频，仅串流视频
-al x     向客户端报告的音频延迟，单位秒（默认 0.25）
-ca [<fn>] 在音频（ALAC）模式下渲染封面图 [或写入文件 <fn>]
-md <fn>  在 AirPlay 音频（ALAC）模式下把元数据文本写入文件 <fn>
-reset n  客户端静音 n 秒后重置（默认 n=15，0=永不重置）
-nofreeze 重置后不要保留冻结画面
-nc       客户端停止投屏时不要关闭视频窗口
-nc no    取消 -nc 选项（照常关闭视频窗口）
-nohold   新客户端连接时断开当前连接
-restrict 仅允许 "-allow <deviceID>" 指定的客户端接入
          UxPlay 会在客户端尝试连接时显示其 deviceID
          使用 "-restrict no" 表示不限制客户端（默认）
-allow <i> 在启用限制时，允许 deviceID = <i> 的设备连接
-block <i> 始终阻止 deviceID = <i> 的设备连接
-FPSdata  显示客户端发来的视频流性能报告
-fps n    设置允许的最大串流帧率，默认 30
-f {H|V|I} 水平翻转|垂直翻转|同时翻转=画面反转=旋转 180 度
-r {R|L}  向右旋转 90 度（顺时针）或向左旋转（逆时针）
-m [mac]  设置 MAC 地址（同时也是 Device ID），用于同时运行多个 UxPlay
          如果未给出 xx:xx:xx:xx:xx:xx 形式的 mac，则使用随机 MAC
-key [fn] 把私钥保存到 $HOME/.uxplay.pem（或文件 "fn"）
-dacp [fn] 把客户端 DACP 信息导出到文件 $HOME/.uxplay.dacp
          （可选改用文件 "fn"）；用于客户端遥控器控制
-vdmp [n] 把 h264 视频输出转储为 "fn.h264"；fn="videodump"，可用
          "-vdmp [n] 文件名" 修改。若给出 [n]，每当出现新的 SPS/PPS NAL
          就新建文件 fn.x.h264（x=1,2,...），且最多转储 n 个 NAL 单元
-admp [n] 把音频输出转储为 "fn.x.fmt"，fmt = {aac, alac, aud}，x
          =1,2,...；fn="audiodump"，可用 "-admp [n] 文件名" 修改。
          音频格式变化时 x 递增。若给出 n，则最多转储 n 个音频包。
          "aud" = 未知格式
-ble [fn] 蓝牙 LE 信标：把数据写入文件 ~/.uxplay.ble
          可选：写入文件 "fn"（"fn" = "off" 表示取消）
-d [n]    启用调试日志；可选：n=1 表示跳过常规数据包日志
-v        显示版本信息
-h        显示本帮助
-rc fn    从文件 "fn" 读取启动选项，而不是 ~/.uxplayrc 等
$UXPLAYRC、~/.uxplayrc 或 ~/.config/uxplayrc 中的启动选项会先被
应用（命令行选项可以覆盖它们）：格式为每行一个选项，不加开头的
"-"；以 "#" 开头的行会被忽略。
